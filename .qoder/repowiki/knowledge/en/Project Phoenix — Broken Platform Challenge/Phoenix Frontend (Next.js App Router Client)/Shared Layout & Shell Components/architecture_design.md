Four sibling React Server Component files, each marked with the `"use client"` directive so they run in the browser. All components consume authentication state exclusively through the shared `useAuth` hook from `@/lib/auth` rather than props or context passed down, making this module a consumer of the auth layer. Routing is handled via Next.js App Router (`next/link`, `next/navigation`) — `NavBar` renders the top header with brand link and logout action, `Sidebar` renders workspace-scoped navigation derived from the current pathname, `RequireAuth` wraps child routes and redirects unauthenticated users to `/login`, and `InfoButton` renders an about/help dialog mounted into `document.body` via `createPortal`. There are no internal sub-packages; cross-component communication goes only through the external auth hook and Next.js router.
