The module is a single Next.js 14 App Router application split by directory role: `src/app/` holds route handlers (workspaces, projects, login), `src/components/` provides the app shell (NavBar, Sidebar, RequireAuth, InfoButton), and `src/lib/` exposes the typed fetch wrapper with GET caching, the React AuthContext provider, and shared TypeScript types. Routes consume the lib layer rather than calling fetch directly, and all page components are composed from the shared UI components — there is no server-side code in this package; it is purely a browser-facing client consumed by the Phoenix backend.
