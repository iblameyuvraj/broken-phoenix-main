Three sibling repositories form one application: `phoenix-backend` (Express + Mongoose API) exposes the REST surface consumed by `phoenix-frontend` (Next.js App Router client), while `phoenix-ci` orchestrates their build, Vercel deployment, and smoke tests against both apps. The root README is the only cross-child contract — it defines the shared MongoDB Atlas connection (`/phoenix` database), demo user accounts, the grader endpoint at `http://13.233.41.22:7070/`, and the acceptance criteria that all three repos must pass together (`npm ci` + typecheck + build in each app, seedable fresh DB, green CI). There is no shared code between children; integration happens through environment variables, the HTTP API, and the external grader.
